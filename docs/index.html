📊 Native Trading AI

Plateforme personnelle de veille d'actifs, de génération de signaux SMC/ICT et d'analyse de marché — 100% locale.

Rust Vue 3 Tauri

Aperçu du graphique

Fonctionnalités

📐 Indicateurs SMC/ICT

Order Blocks, BOS, FVG, MSS, CHOCH, Sweep, OTE, Kill Zones — moteur Rust v12 (20+ indicateurs).

🚀 3 stratégies

SMC directionnel, Rockets (VCP), Volatilité (Straddle) avec scoring et lifecycle intrabar.

🧠 Intelligence artificielle

Pipeline LSTM + XGBoost sur GPU local (RTX 3090). Coach IA via Ollama.

📡 Veille multi-actifs

Forex, cryptos, métaux, indices. Streaming temps réel + alertes Telegram.

🔄 Prochaine étape : Intégration TradingView Advanced Charts

Cette application utilise actuellement lightweight-charts pour le rendu graphique. L'objectif est d'intégrer la TradingView Charting Library (Advanced Charts) pour bénéficier du moteur Pine Script natif, de la barre d'outils complète, du système d'alertes, et de la bibliothèque d'indicateurs — tout en conservant le backend Rust pour la génération de signaux serveur.

Architecture technique

Backend : Rust workspace (12 crates : api, smc, strategies, ml, data, indicators, llm, news, notifications, risk, db, common).
Frontend : Vue 3 + TypeScript + Tailwind CSS + Tauri (app desktop native).
Données : SQLite (3M+ bougies), streaming Bybit + IG Markets.
